Speech codec listening test

Before you start

  1. You will hear short sentences (5 seconds) coded by different speech codecs, and rate how close each version sounds to the original.
  2. In each trial, play the Reference, then each unlabelled version. Rate each one from 0 (bad) to 100 (excellent, indistinguishable from the reference).
  3. One version in every trial is the reference itself: give it 100. One is deliberately very poor.
  4. In Loop mode, switching between versions keeps the playback position, so you can compare the same words. You can drag the bar to move within the excerpt.
  5. Each trial takes about half a minute. Do as many as you like and press Stop here whenever you want to end; every trial you finish is saved as soon as you move on.

Please use headphones in a quiet room. Set a comfortable volume on the reference in the first trial and do not change it afterwards.
